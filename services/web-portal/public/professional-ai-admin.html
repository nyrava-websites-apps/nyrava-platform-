Groq and OpenRouter

Use Groq with your free or paid Groq account. For GPT-4o mini, use an OpenRouter key with credits and explicitly select Paid models. A key alone does not switch paid use on.

Enable only your chosen provider for predictable draft routing. If several are enabled, drafts use OpenAI first, then Groq, then OpenRouter; lead review can call each enabled provider. Paid providers are not automatically enabled as fallback.

Traffic protection: one active request per provider, ten-second spacing, bounded context and output, minute/day budgets, and shared cooldowns. Paid mode retains these conservative limits.
