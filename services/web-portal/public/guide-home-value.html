GUIDE · HOME VALUES

Better property details support a more useful report.

A property estimate is only as useful as the property match and available sales evidence behind it.

Use the exact address

Include the unit number where applicable, city, state, and ZIP. Nearby properties can differ substantially; the right neighborhood alone is not an exact property match.

Enter measurements carefully

Use the most reliable living-area, bedroom, bathroom, and property-type information available. Do not confuse lot area with interior living area.

Describe features without guessing

Record known improvements and property features. Unknown does not mean absent. A renovation should not be treated as a guaranteed dollar adjustment without supporting local evidence.

Read the limitations

Comparable sales may be insufficient or differ in condition, size, or timing. An automated report can support a conversation, but it is not a formal appraisal or guaranteed sale price.
